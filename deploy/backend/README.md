# FDPIS API: deployment files

- `Dockerfile` builds the runtime image for Render (free plan, 512 MB). Its build context is the **repo root**.
- `Dockerfile.test` builds the runtime image plus scikit-learn, and runs the parity and Layer 5 tests.
- `requirements*.txt` pin exact versions.
- `artifacts/` holds the slim serving data and models. It is committed and generated by `python deploy/build_space.py`.
- `testdata/` holds the two test-only files. It is gitignored and generated by the same script.

See `deploy/README.md` and `deploy/ARTIFACT_MANIFEST.md`.
